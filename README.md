# 🏠 House Price Prediction

This project uses a Linear Regression model to predict house prices based on:

- GrLivArea (Above-ground living area)
- OverallQual (Overall quality)
- GarageCars (Garage capacity)
- TotalBsmtSF (Total basement area)

## 📦 Files
- `train.csv`: Training dataset
- `test.csv`: Test dataset for predictions
- `sample_submission.csv`: Format for final output
- `house_price_model.ipynb`: Notebook with all code
- `submission.csv`: Generated file with predictions

## 🔧 Tech Stack
- Python
- Pandas
- Scikit-learn

## 🚀 How to Run
1. Open the notebook
2. Run all cells
3. Upload the generated `submission.csv` to the competition platform or GitHub
